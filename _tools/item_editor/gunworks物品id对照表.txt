────────────────────────────────────────
【三】编辑器导出后怎么进包
────────────────────────────────────────
1. 导出目录随便选(如桌面), 得到 items/ + icons/ 两个文件夹。
2. 新物品: JSON 复制进 packs/gunworks/items/, PNG 复制进 packs/gunworks/icons/。
3. 已注册物品: 见上面 ※, 只合 shape+icon 两段; PNG 直接复制进 icons/。
4. 文件名已自动取冒号后名部分(gunworks:gw_pistol → gw_pistol.json/.png),
   与包内现有文件同名即覆盖, 直接对得上。
5. 重启游戏生效; F12 发放全部注册物品检查贴图/形状。
