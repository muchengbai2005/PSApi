# 08 · 实战讲解：三个真实内容包带读

> 前七章是**零件图册**：每个字段、每个函数单独讲。
> 本章是**总装车间**：把零件装回三个真实存在、可以直接运行的内容包里，
> 逐文件带你读一遍——读完你会知道"一个完整的包长什么样"。

## 三个包的定位

三个包都在 `UserData/PSApi/packs/` 下，随游戏自带、开箱可玩：

| 包 | 规模 | 定位 | 带读价值 |
|---|---|---|---|
| `example_hello` | 24 文件 | **入门示范包**：每样能力给一个最小例子 | 数据面三件套（物品/机器/配方/品质）的标准写法 |
| `gunworks` | 67 文件 | **全特性实战包**：剧情 NPC 网络 + 机器玩法 + 经济闭环 | 全书所有系统在同一个包里的协同 |
| `psapi_manager` | 3 文件 | **系统包**：F6 管理面板本体 | PSUI 动态面板的官方样板（on_build 命令式填充） |

## 带读方法

每篇的写法固定：

1. **先看文件清单**——这个包用哪些文件实现了什么；
2. **再读关键代码**——摘录真实源文件并讲解（不是缩写版伪码，是与磁盘上完全一致的代码）；
3. **最后给"抄什么"**——你做自己的包时，哪段可以直接照抄、哪段是包特有的设定。

> 篇中引用的其他章节知识不再重复展开，都给出跳转链接。
> 三个包的完整源文件是最好的补充读物：路径见各篇篇首。

## 版本事实

- 三包随当前游戏内置：PSApi.Events **v1.13.1** / PSApi.Items **v0.9.3**。
- `gunworks` 声明的最低依赖是 Events ≥ v1.11.0 / Items ≥ v0.9.3（其中
  `price` 三系数、`{buy_list}` 等键需要更高版本，正文逐处标注）。
- `example_hello` 部分能力（品质层、自装配窗口）来自更早版本，仍是有效写法。
