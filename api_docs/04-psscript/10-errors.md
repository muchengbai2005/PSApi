# 04-10 · 错误与调试

> PSScript 的错误分**编译期**与**运行期**两类，现场都在日志。本篇讲错误格式、
> 两道熔断保险、常见错误对照表与调试套路。

## 两类错误

```text
编译期(词法/语法): 启动装载时一次过, 报 文件:行:列 —— 整个文件不加载
运行期(执行时):    顶层或 handler 执行中抛出, 报 文件:行 —— 只中断当前段
```

关键区别：**编译错误让文件缺席**（连顶层都不跑、on 块也不登记），
**运行错误只断当段**（这个文件后面的顶层语句不跑，但其他文件、其他 handler 照常）。

## 编译期错误

格式（源码 `PsCompileError`）：

```text
<包id>/<events下的相对路径>:<行>:<列>: <消息> (该文件未加载)
```

例如在 `my_pack/events/main.pss` 第 4 行忘写冒号：

```pss
var x = 1
if x > 0
    log.info("hi")
```

控制台与 `UserData/PSApi/logs/pack_errors_*.log` 会出现：

```text
[pss] compile error: my_pack/main.pss:2:10: 应为 ':', 实为 标识符 'log'
my_pack/main.pss:2:10: 应为 ':', 实为 标识符 'log' (该文件未加载)
```

排查要点：

- **行:列指向出错 token**（不是你"以为错的地方"）——错误在上一行末尾时，
  报的位置常在下一行开头，这是递归下降解析器的通性。
- 一个文件只报**第一个**错误（后续解析无意义）；修一个重启动再看下一个。
- 错误汇总文件在 `UserData/PSApi/logs/`，同时控制台有 `[pss] compile error:` 行。

### 常见编译错误对照

| 消息 | 原因 | 修法 |
|---|---|---|
| `应为 ':', 实为 ...` | if/for/func/on 头缺冒号 | 行尾补 `:` |
| `应为 '='(const 必须有初始值)` | `const X` 没赋值 | 补 `= 值` |
| `缩进混用空格与制表符` | 文件里 tab/空格混用 | 编辑器统一转 4 空格 |
| `空格缩进须为 4 的倍数(当前 N 个)` | 缩进 2/6 空格 | 调成 4 的倍数 |
| `缩进层级未与任何外层块对齐` | dedent 回退位置不匹配 | 对齐到外层块的缩进 |
| `'on' 块只能出现在文件顶层` | 函数里写 on | 移到顶层 |
| `赋值目标必须是变量/索引/成员` | `f() = 1` 之类 | 换合法目标 |
| `语句后应为行尾(一行一条语句)` | 一行写了多条 | 拆行 |
| `字符串未闭合(不支持跨行)` | 引号没配对 | 检查引号 |
| `插值表达式内的字符串引号须与外层不同` | `"{"x"}"` | 外双内单 |
| `字典键须为字符串字面量或标识符` | 键写了数字/表达式 | 键只能是字符串/标识符 |
| `空语句块(至少一条语句, 或用 pass 占位)` | 块体为空 | 补 `pass` |
| `带默认值参数之后的参数也必须有默认值` | `func f(a, b=1, c)` | 给 c 也配默认值 |

## 运行期错误

格式（源码 `PsScriptEngine`）：

```text
顶层:  [pss] <包id>/<相对路径>:<行> in 顶层: <消息>
事件:  [pss] <包id>/<相对路径>:<行> in <事件名>: <消息>
```

例：

```text
[pss] my_pack/main.pss:7 in 顶层: 未定义变量 'prices'
[pss] my_pack/main.pss:12 in shop_opened: 除以零
```

排查要点：

- 行号是**抛错语句的行**，直接跳过去看。
- 顶层错误只断**本文件**：后面还有顶层语句也不执行了，但其他文件与所有 on 块正常。
- handler 错误只断**本次触发**：下次事件来了照样执行（若 bug 未修，每次都报——
  反复出现的同一条错误通常就是事件驱动的 bug 特征）。

### 常见运行错误对照

| 消息 | 原因 | 修法 |
|---|---|---|
| `未定义变量 'x'` | 名字不存在（拼错/条件声明未执行/跨包访问） | 检查拼写与作用域 |
| `不能给常量 'X' 赋值` | const 再赋值 | 改 var 或删赋值 |
| `除以零` / `对零取模` | int 运算分母为 0 | 先判零 |
| `类型 X 与 Y 不支持算术运算` | 数字×字符串等 | 明确类型；拼接用 `+` 仅限 string/array |
| `类型 X 与 Y 不能比较大小` | 非数字/非字符串比 `<` | 类型统一后再比 |
| `索引越界: N(长度 M)` | 数组下标出界 | 先查 `len`；负索引倒数 |
| `索引须为整数` | `arr[1.0]` / `arr["1"]` | 用 int 索引 |
| `字典索引须为字符串` | `d[0]` | dict 键是字符串 |
| `类型 X 不支持成员访问 '.'` | 对数字/数组点号访问 | 检查左侧类型 |
| `命名空间 X 无成员 'y'` | API 名拼错 | 查 [05 API 参考](../05-api-reference/README.md) |
| `类型 X 不可迭代(for 需要 array/dict/string)` | for 了数字/null | 检查数据源 |
| `类型 X 不可调用` | 调了非函数（如 `x()` 而 x 是 dict） | 检查括号 |
| `函数 f() 缺少必填参数 'x'` | 实参不够 | 补参数或加默认值 |
| `函数 f() 最多 N 个参数, 实传 M` | 实参过多 | 删多余实参 |
| `len() 不支持类型 ...` 等 | 参数类型不符 | 看函数签名表 |

## 两道熔断保险

解释器对失控代码有硬性保护（源码 `Interpreter`）：

| 保险 | 预算 | 超限错误 | 语义 |
|---|---|---|---|
| 步数预算 | **100,000 步/段** | `执行步数超过预算(100000), 疑似死循环` | "一段" = 一个文件的顶层，或一次事件触发；每段重新计数 |
| 调用深度 | **64 层** | `调用深度超过上限(64), 疑似无限递归` | 嵌套调用（含内置函数内部回调脚本函数）总深 |

触发熔断 = 该段终止 + 记一条运行错误，游戏本体不受影响。

> 实践含义：**tick/循环里别做重活**。`tick` 每秒触发，若 handler 需要 5 万步以上，
  每秒都在烧预算；大计算拆到事件里（day_wake）或用 state 记进度分帧做。

## 调试套路

### 1. 打印优先

PSScript 没有断点调试器，`log.*` 就是调试器：

```pss
var data = load_something()
log.info("[debug] data={data} type={type(data)} len={len(data)}")   # 结构+类型+长度三连
```

三个级别落 MelonLoader 日志（前缀 `[pss 包id]`）：

```pss
log.info("常规信息")    # MelonLoader Msg
log.warn("可疑情况")    # Warning(黄色)
log.err("出错了")       # Error(红色)
```

### 2. 二分定位

某文件顶层报错但看不出哪行：把文件从中间注释一半（每行加 `#`），
重启——错误消失则问题在后半，继续二分。（编译错误也适用此法。）

### 3. 类型三问

遇到"类型 X 不支持 ..."系列，先问三个问题：

```pss
log.info("{type(x)}")     # 1. 它到底是什么类型?
log.info("{x}")           # 2. 它的值/内容是什么?
log.info("{len(x)}")      # 3. 它有多长?(容器)
```

90% 的运行错误是"以为是 A 类型实际是 B"——尤其 `null`（函数没写 return、
dict 缺键、pop 空数组、find 没找到，全都悄悄给你 null）。

### 4. 事件不触发的排查清单

on 块写了但从不执行，按序检查：

1. 文件加载了吗？——启动时顶层放一条 `log.info("loaded")` 验证（能推出说明文件活着）。
2. 事件名拼对了吗？——对照 [09 事件](09-events.md#15-个桥接事件全表)；表外名字看启动警告。
3. 自定义事件用字符串形式订阅了吗？——`on "my_pack:x":` 而非 `on my_pack_x():`。
4. 是触发条件没满足，不是没触发？——`shop_opened` 要真的拉卷帘门，`night_services` 要睡觉到次日。

### 5. 每日一次 vs 永远不跑

用 state 防重的逻辑（[09 事件](09-events.md)）测试期容易把 state 撑满：
`"daily_" + str(time.day())` 之类的键今天的日期已记账，当天再也不会触发。
**测试期最粗暴的办法：删档或换存档槽**（state 按槽隔离）；或给键加版本后缀
`"daily_v2_" + str(time.day())`。

## 附录：语言层内置函数全表

本章涉及的**语言层**函数（游戏层 API 见下一章）：

| 函数 | 签名 | 说明 |
|---|---|---|
| `len` | `len(x)` | 长度：string/array/dict |
| `str` | `str(x)` | 转打印文本（与插值一致） |
| `int` | `int(x)` | 转 int（float 截断；string 解析失败报错） |
| `float` | `float(x)` | 转 float |
| `bool` | `bool(x)` | truthy 转换 |
| `type` | `type(x)` | 类型名字符串 |
| `range` | `range(终点)` / `range(起, 终[, 步长])` | 整数数组（终不含） |
| `push` | `push(arr, v)` | 尾部追加 |
| `pop` | `pop(arr)` | 弹出末元素（空返回 null） |
| `keys` | `keys(dict)` | 键数组 |
| `values` | `values(dict)` | 值数组 |
| `has` | `has(容器, x)` | dict 键 / array 值 / string 子串 |
| `remove` | `remove(dict, 键)` / `remove(arr, 值)` | 删除，返回 bool |
| `join` | `join(arr[, 分隔符])` | 数组转字符串 |
| `split` | `split(str, 分隔符)` | 字符串转数组 |
| `format` | `format(模板, 参数...)` | `{}`/`{0}` 占位模板 |
| `rand` | `rand(上界)` / `rand(下, 上)` | 整数随机（前者 0..上界-1，后者闭区间） |
| `randf` | `randf()` / `randf(下, 上)` | 浮点随机（默认 [0,1)） |
| `floor` / `ceil` | `floor(x)` / `ceil(x)` | 取整（返回 int） |
| `abs` | `abs(x)` | 绝对值 |
| `min` / `max` | `min(a, b)` / `max(a, b)` | 较小/较大值（数字） |
| `clamp` | `clamp(x, 下, 上)` | 夹取到区间 |
| `log.*` | `log.info/warn/err(text)` | 日志 |
| `bus.emit` | `bus.emit("包id:事件"[, dict])` | 广播自定义事件 |
