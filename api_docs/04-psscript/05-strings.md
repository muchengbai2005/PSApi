# 04-05 · 字符串与插值

> `"{expr}"` 字符串插值是 PSScript 的招牌能力：任何字符串里直接嵌表达式。
> 本篇讲插值语法、引号规则、转义，以及 str/join/split/format 四件套。

## 基本规则

```pss
var a = "双引号字符串"
var b = '单引号字符串'     # 两者完全等价, 挑一个用即可
```

- 单行：字符串**不能跨行**（未闭合是编译错误）。
- `+` 拼接：任一侧是 string 就把两边转成文本连接（`"a" + 1` → `"a1"`）。
- 不可变：所有"修改"都是产生新串（`label += "!"` 是新建再赋值）。
- `len(s)` 求长度，`s[i]` 取单字符（负索引可用），`in` 判子串。

## 插值：`"{表达式}"`

字符串里 `{...}` 中的内容会作为**表达式**求值并拼进文本：

```pss
var name = "老猫"
var price = 500
log.info("买家 {name} 出价 {price}")          # 买家 老猫 出价 500
log.info("折后 {price * 0.8}")               # 插值里可以是任意表达式
log.info("库存 {[1,2,3]}")                   # 数组也能插: [1, 2, 3]
```

插值表达式的完整能力（等同一个普通表达式）：

```pss
var tags = ["hot", "clean"]
log.info("第 {len(tags)} 个标签是 {tags[1]}")          # 索引/函数调用
log.info("{'hot' in tags}")                            # 逻辑表达式
log.info("估价 {price_with_tax(price)}")               # 调自己的函数
log.info("嵌套 {"{"}花括号见下节{"}"}")                # 见转义
```

**值转文本的规则**（与 `str()`、log 输出完全一致）：

| 值 | 文本 |
|---|---|
| null | `null` |
| bool | `true` / `false` |
| int / float | 数字本身（`3` / `3.5`） |
| string | 原样（不加引号） |
| array | `[a, b]` 递归展开（最深 4 层，再深显示 `[...]`） |
| dict | `{k: v, ...}` 递归展开 |
| function | `<func 名字>` |
| handle | `<client handle>` 之类 |

### 引号规则：外双内单（重要）

插值表达式里如果还要写字符串，**必须换一种引号**：

```pss
var name = "老猫"
log.info("你好 {name}")                  # OK
log.info("你好 {'老猫' + '!'}")          # OK: 外层 " 内层 '
log.info("你好 {"老猫"}")                # 编译错误! 内层引号与外层相同
log.info('你好 {"老猫"}')                # OK: 外层 ' 内层 "
```

### 花括号转义：`{{` 与 `}}`

想在文本里输出字面 `{` `}`，写双份：

```pss
log.info("模板是 {{name}} 占位")         # 模板是 {name} 占位
```

这也解释了 `format()` 为什么用同样的转义（见文末）。

### 插值的限制

- `{}` 空插值是编译错误（`插值表达式不能为空`）。
- 插值表达式内不能换行（编译错误：未闭合）。
- 插值内不能再用与外层相同的引号（见上）。

## 转义序列

普通字符串（无论单双引号）支持反斜杠转义：

| 写法 | 含义 | | 写法 | 含义 |
|---|---|---|---|---|
| `\n` | 换行 | | `\\` | 反斜杠 |
| `\t` | 制表符 | | `\"` | 双引号 |
| `\r` | 回车 | | `\'` | 单引号 |
| `\{` | 字面 `{` | | `\}` | 字面 `}` |

未知的转义（如 `\q`）**原样保留**（输出 `\q` 两个字符），不报错。

> `\{` 与 `{{` 效果相同，都能输出字面花括号——`{{` 更直观，推荐。

## format()：位置模板

当模板和参数分开存放（比如模板来自配置、参数后算出来）时，用 `format()`：

```pss
format("{} 掷骰 d6 得 {}, 随机价 {}", PACK, rand(1, 6), 250)
# → "my_pack 掷骰 d6 得 4, 随机价 250"

format("{0} vs {1}, 赢家 {0}", "甲", "乙")     # 索引占位可重复引用
# → "甲 vs 乙, 赢家 甲"

format("字面花括号 {{}}")                       # → "字面花括号 {}"
```

| 占位符 | 含义 |
|---|---|
| `{}` | 按顺序取下一个参数（auto 计数） |
| `{0}` `{1}` | 按索引取参数（从 0 开始） |
| `{{` `}}` | 字面花括号 |

规则：`{}` 与 `{索引}` 可混用但容易乱，建议二选一；索引超出参数个数是运行错误；
模板缺少 `}`、占位符内容不是数字都是运行错误。

插值优先，format 兜底——**日常写死文本用 `"{x}"`，模板是变量时才用 format**。
教学示例里两种写法常并存（如 `log.warn("format: " + format(...))`），
对照包见 [ex13_pss_strings](../../examples/ex13_pss_strings/README.md)。

## 字符串工具函数

```pss
len("hello")                # 5
"hello"[1]                  # "e"
"cat" in "concatenate"      # true
split("a,b,c", ",")         # ["a", "b", "c"]   分隔符不能为空串
join([1, 2, 3], "|")        # "1|2|3"           元素自动转文本
join(["a", "b"])            # "ab"              分隔符可省略=空
str(3.5)                    # "3.5"
str([1, "x"])               # "[1, x]"
```

`join` 与 `split` 互为逆操作，是"数组 ↔ 字符串"的桥：

```pss
var names = ["老猫", "博士", "警长"]
log.info("今日访客: {join(names, '、')}")     # 今日访客: 老猫、博士、警长
```

**注意**：没有 `upper/lower/trim/replace/startswith` 这类文本处理函数（v1.13.1）。
需要截取用 `s[i]` 逐字符 + `join`，需要判断前后缀用 `in` 或索引比较；
复杂文本处理建议在数据面 JSON 里预处理好。

## 常见错误对照

| 写法 | 结果 | 正确姿势 |
|---|---|---|
| `"嵌套 {"x"}"` | 编译错误：插值内引号 | 换引号 `"嵌套 {'x'}"` |
| `"文本 {x}。"`（x 未定义） | 运行错误：未定义变量 | 先确认变量存在 |
| `"a" * 3` | 运行错误：字符串不支持乘法 | 直接写 `"aaa"`；动态重复用循环 push |
| `split("a,,b", ",")` | `["a", "", "b"]`（空段保留） | 需要过滤就 for + 判空 |
| `"{"}"` | 编译错误 | `"{{}}"` 或 `"\{\}"` |
