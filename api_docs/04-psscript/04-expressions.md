# 04-04 · 运算符与表达式

> 本篇讲全部运算符的**精确语义**：算术的 int/float 规则、比较、逻辑短路、
> `in`、索引（含负索引）、成员访问。很多行为"像 Python 但不完全一样"，
> 对照表帮你避开细节坑。

## 运算符总表（按优先级从低到高）

| 优先级 | 运算符 | 说明 |
|---|---|---|
| 1（最低） | `or` | 逻辑或，短路 |
| 2 | `and` | 逻辑与，短路 |
| 3 | `not` | 逻辑非（一元） |
| 4 | `==` `!=` `<` `<=` `>` `>=` `in` | 比较，**非结合**（见下） |
| 5 | `+` `-` | 加减 |
| 6 | `*` `/` `%` | 乘除模 |
| 7 | `-`（一元） | 取负 |
| 8（最高） | `()` `[]` `.` 后缀 | 调用、索引、成员 |

括号 `(expr)` 可以随时提升优先级。没有的三目 `?:`、位运算、`++`/`--`。

## 算术运算

```pss
log.info("{1 + 2}")        # 3
log.info("{7 / 2}")        # 3      int / int = 截断整数! (不是 3.5)
log.info("{7 / 2.0}")      # 3.5    任一方是 float → float
log.info("{7 % 3}")        # 1      取模
log.info("{2 * 3 + 4}")    # 10     乘法先于加法
log.info("{-(2 + 3)}")     # -5     一元负号
```

核心规则（与 GDScript 2.x 一致）：

| 组合 | 结果 | 例子 |
|---|---|---|
| int ⊕ int | **int**；`/` 截断，`%` 整除余数 | `7 / 2` → `3`；`-7 / 2` → `-3` |
| 任一方 float | float | `1 + 0.5` → `1.5` |
| `0` 做除数/模数 | **运行错误**（除以零 / 对零取模） | `1 / 0` → 报错，不是 inf |
| 数字 × 字符串 | **运行错误** | `"a" * 3` 不合法 |

> **最容易踩的坑**：`total / count` 两个 int 想要小数结果，必须写
> `total / float(count)` 或 `total * 1.0 / count`。算折扣、算百分比前先想想类型。

`+` 还承接两种拼接（详见 [05 字符串](05-strings.md) 与 [08 容器](08-containers.md)）：

```pss
log.info({"a" + 1}")       # a1     任一侧是 string → 字符串拼接
var merged = [1, 2] + [3]  # [1,2,3] 两侧都是 array → 数组拼接(产生新数组)
```

## 复合赋值

```pss
var n = 10
n += 5      # 15
n -= 3      # 12
n *= 2      # 24
n /= 5      # 4 (int/int 截断, 与 /= 语义一致)

var label = "a"
label += "b"     # ab   (字符串拼接同样适用)

var list = [1]
list += [2, 3]   # [1,2,3] 等价 list = list + [2,3]
```

复合赋值与二元运算是同一套语义（读出 → 运算 → 写回）。没有 `%=`、`//` 等。

## 比较运算

```pss
1 == 1.0        # true   int/float 跨类型按数值比较
"abc" == "abc"  # true   字符串按内容
[1,2] == [1,2]  # false! 数组/字典是引用比较(不是逐元素深比)
"10" == 10      # false  string 与 int 类型不同 → false
null == null    # true
```

精确规则：

- 数字之间：跨 int/float 按数值比（`1 == 1.0` 为 true）。
- 字符串：按内容。
- **数组、字典、函数：按引用**（同一个对象才相等）。内容相同的两个数组不相等。
- 类型不同的非数字值：直接 false。
- `!=` 是 `==` 的反。

大小比较 `< <= > >=`：

```pss
1 < 1.5        # true    数字跨类型按数值
"apple" < "banana"  # true  字符串按码点序(Ordinal)
"a" < 10       # 运行错误: 不能比较大小(仅数字↔数字, 字符串↔字符串)
```

**比较是非结合的**：一条表达式最多一个比较运算符。

```pss
1 < x < 10     # 编译错误!(应为 行尾/表达式) —— 不支持链式比较
1 < x and x < 10   # 正确写法
```

## 逻辑运算与短路

```pss
var name = ""
if name and len(name) > 0:   # name 是 "" → falsy, 右边不执行(短路)
    pass

if not has(stock, "hot"):    # not 一元
    log.info("没有烫手货")
```

- `and`：左边 falsy → 直接返回**左值**（不返回 bool！）；否则返回右值。
- `or`：左边 truthy → 返回左值；否则返回右值。
- `not`：恒返回 bool。

```pss
var client_name = event.get("name") or "匿名"   # 惯用默认值写法
```

短路保证安全性——右边可以是"左边为假时执行会出错"的表达式：

```pss
# items.find 找不到返回 null, 直接 .id 会报错; 先判空就不怕
var it = items.find("game:newspaper")
if it != null and it.count > 2:
    log.info("报纸库存充足")
```

## in 运算符

`x in 容器`，按容器类型分派：

```pss
"hot" in ["clean", "hot"]     # true   数组: 按值找元素
"hp" in {"hp": 10, "mp": 5}   # true   字典: 查键
"cat" in "concatenate"        # true   字符串: 子串查找
3 in [1, 2, "3"]              # false  类型不同的元素不匹配
1 in 100                      # 运行错误: 类型 int 不支持 in 运算
```

左操作数要求：dict 的 `in` 左边须为字符串（键）；string 的 `in` 左边须为字符串（子串）。
数组则按 `==` 语义逐元素找。判断成员还有个等价函数 `has(容器, x)`（
[08 容器](08-containers.md)），`in` 是表达式、`has()` 是函数，选顺手的用。

## 索引访问 `[]`

```pss
var stock = ["rifle", "medkit", "scrap"]
log.info("{stock[0]}")      # rifle
log.info("{stock[-1]}")     # scrap   负索引从尾部数(-1 = 最后一个)
log.info("{stock[3]}")      # 运行错误: 索引越界: 3(长度 3)

var deal = {"price": 500}
log.info("{deal['price']}")   # 500
log.info("{deal['nosuch']}")  # null   字典缺键宽容返回 null(不报错!)

var s = "hello"
log.info("{s[1]}")            # e      字符串按下标取单字符
```

规则：

| 容器 | 索引类型 | 越界/缺键 |
|---|---|---|
| array | 必须 int（负数=倒数） | 运行错误 `索引越界` |
| dict | 必须 string | **返回 null**（不报错） |
| string | 必须 int | 运行错误；返回的是单字符字符串 |

> 索引只能是**整数字面量或整数值**；写 `arr[1.0]` 会报错（`索引须为整数`）。

## 成员访问 `.`（点号）

点号按对象的类型分派，一张表看全（这是 PSScript 最"多义"的运算符）：

| 对象 | 语义 | 读不存在的成员 | 可赋值 |
|---|---|---|---|
| dict | 按键读值 | **返回 null**（与 `[]` 一致） | 可以（`d.k = v` 等价 `d["k"] = v`） |
| namespace（log/state/...） | 取成员函数/常量 | 运行错误，列出该命名空间 | 不可以 |
| handle（client/item） | 读游戏对象属性/方法 | 运行错误，列出可用成员 | 不可以（用方法改） |
| 其他（数字/字符串/数组） | — | 运行错误 `不支持成员访问` | — |

```pss
var deal = {"buyer": "老猫", "price": 500}
log.info("{deal.buyer}")      # 老猫   点号与 ['buyer'] 完全等价
log.info("{deal.note}")       # null   缺键不报错——事件 dict 的常态
deal.price += 50              # 点号赋值 OK
deal["tag"] = "vip"           # 方括号赋值 OK

log.info("{time.day()}")      # namespace: 方法调用
# log.abc                     # 运行错误: 命名空间 log 无成员 'abc'
```

> **为什么缺键返回 null 是"常态"？** 事件 payload 是 dict（`event.save_slot`、`event.day`），
> 不同事件带的字段不同；宽松读法让你写 `if event.save_slot:` 而不用先判键存在。

点号/括号/下标可以任意链式（后缀优先级最高，从左到右结合）：

```pss
log.info("{deal['items'][0].name}")    # 链式: 字典→数组→字典
```

## 表达式 vs 语句

最后明确语法边界（写复杂代码前的常识）：

- 赋值是**语句**不是表达式：`x = y = 1` 不合法；也不能 `if x = 1:`（判等须写 `==`）。
- 函数调用既是表达式也是合法语句（单独一行调用、丢弃返回值，如 `push(arr, 1)`）。
- 没有逗号表达式、没有分号多语句。
