## 四、给读者的使用建议

- 写包时**不要依赖**第一节表内的不确定行为（尤其 #2 自定义 crime_id 的
  展示效果——有 mod 用了它，但展示层行为未实证）；
- 引用本书时，推测点可自由改写（它们不是规范），[待确认] 事项等官方答复；
- 发现本书与源码/游戏实况不符：**以源码为准**，并欢迎按
  [01 · 工作流](../01-getting-started/04-workflow.md) 的排障路径复核后修订本书。
