## 关于"原版物品 id 对照表"

原计划附录提供原版物品 id 全表，**实际不提供**，原因：

- 游戏在 2026-09-18（playtest）更新后，既有物品参考（items_catalog 9-4、
  IsilDump 9-9 等）全部过期；唯一新实证是 9-21 的 loot table dump，
  只覆盖掷骰池条目。
- 在没有可靠新 dump 之前，任何"全表"都会是编造。

**替代方案**（如何查一个原版物品 id 是否存在/叫什么）：

| 方法 | 入口 | 说明 |
|---|---|---|
| F6 物品浏览器 | 游戏内 F6 | 30 分类 + 名称/ID 搜索，所见即当前版本实况 |
| 运行时校验 | Events v1.11.0 起 | 摆货/注入点对无效 id **跳过 + WARNING**（不再静默）——日志会替你排雷 |
| 掷骰池 dump | `UserData/probe/` | 拾荒/远征池的物品清单（subset） |

给包作者的建议：**引用原版裸 id 的每一处，都在 `//` 注释里
记下核实日期**；游戏更新后按日志 WARNING 逐个复查。
