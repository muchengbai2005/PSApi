# 07 · item_editor 物品编辑器

> 工作区自带的可视化物品制作工具：`_tools/item_editor/item_editor.py`（Python/Tkinter，与 PSApi 运行时无关——它只生成内容包文件，不参与游戏加载）。工具自带完整操作手册见 `_docs/README-物品编辑器.md`，本篇从**模组开发工作流**视角讲怎么把它嵌进内容包生产线。

---

## 一、定位与边界

| 能做 | 不能做 |
|---|---|
| 36×36 网格涂物品形状（对应游戏背包，16px/格） | machines / recipes / qualities / 本地化（导出后手写 JSON） |
| 填写核心字段：模板/名称/描述/价值/46 种游戏标签/违禁品等级/颜色 | NPC、inject、PSUI（全是 `.pss` 脚本侧的活） |
| 图片导入/缩放/旋转/与物品**绑定**，导出时渲染成图标 PNG | 直接写进 `UserData/PSApi/packs/`（导出是两目录结构，需手动复制） |

## 二、环境与启动

```
_tools/item_editor/
├─ item_editor.py      ← 主程序
├─ run_editor.bat      ← 双击启动
├─ test_editor.py      ← 42 项无头功能测试(python test_editor.py)
└─ game_templates.json ← 原版模板快照(候选兜底)
```

依赖：Python 3 + Pillow + tkinterdnd2（拖拽图片用）。无头环境验证装没装好：`python item_editor.py --smoke`。

模板下拉候选优先实时解析 `UserData/items_catalog.md`（363 项原版物品目录），找不到该文件才用脚本旁快照 `game_templates.json`——**保持 items_catalog.md 在最新游戏版本下生成**，模板候选才不会过期。

## 三、五步工作流

### 第 1 步：涂格子定形状

**Ctrl + 左键**按住涂抹：第一格任意，之后每格必须与已选格四向相邻（红框 = 非法：重叠/不相邻），松开 Ctrl 生成物品。不规则形状（L 形、条形）就是它存在的意义。

### 第 2 步：填属性

选中物品后右侧面板：模板（下拉过滤，决定贴图/行为基座——**留空 = 目录第一个物品，务必显式选**）、id（规范要求 `包名:物品名`，无前缀导出时警告）、名称/描述/风味、价值、标签多选（46 种，界面显示中文对照、导出写英文 id）、违禁品等级（无/低/中/高/严重 → 游戏 Contraband 特性 1-4 级）。

> **不要手写 CONTRABAND 标签代替违禁品等级**——安检与 tooltip 只认 `InitContrabandItem` 的内部状态，编辑器导出的 `contraband` 字段才会走到那条路径。

### 第 3 步：图片绑定（最容易返工的一步）

推荐顺序：导入图片（按钮或拖入窗口）→ 拖动/滚轮缩放/Shift+滚轮横向/Alt+滚轮纵向/Q·E 旋转到与格子耦合 → 点工具栏"**图片适配物品**"一键缩放居中 → 选中物品按 **X** 进入绑定模式 → 点击图片完成绑定。

绑定后图片与物品成为一体：拖动格子图片跟随、旋转物品偏移同转（图片宽高不互换——旋转 90° 自带方向）。已绑定再按 X 解绑。

### 第 4 步：预览

"预览图标"按钮看导出效果（透明背景、尺寸 = 占格 × 16px）。不满意回第 3 步。

### 第 5 步：导出并组装内容包

"导出 JSON+图标"到任意目录，得到：

```
<导出目录>/
├─ items/<名>.json    ← 每物品一个（id 冒号后取名部分, gunworks:x → x.json）
└─ icons/<名>.png     ← 每物品一个图标
```

复制进你的包，按需手补高级字段：

```
UserData/PSApi/packs/<你的包>/
├─ pack.json
├─ items/    ← 编辑器导出的 JSON 放这(每个文件 schema: "psapi.items/1")
├─ icons/    ← 导出的 PNG 放这(icon.file 按文件名解析)
├─ machines/ ├─ recipes/ ├─ qualities/   ← 手写(见 03 章数据面各篇)
```

编辑器不生成、但框架已支持的字段（手写进导出 JSON）：`directory`（目录覆盖）、`types`/`typesMode`、`stack`（堆叠）、`qualities`/`defaultQuality`（品质层）、`machine`（机器引用）、`test`（F6 测试分类）。字段规范见 [03 数据面 · 物品](../03-items/02-items.md)。

## 四、快捷键速查

| 操作 | 效果 |
|---|---|
| **Ctrl+左键** 涂抹 | 添加物品格子（四向相邻约束） |
| 左键点击/拖动 | 选中物品 / 按格移动（绿框可放/红框冲突自动还原） |
| **R** / **Shift+R** | 顺/逆时针旋转 90°（冲突则取消） |
| **Ctrl+Z / Ctrl+Y** | 撤销 / 重做（30 步） |
| Delete | 删除选中物品/图片 |
| **X**（选中物品） | 绑定模式 → 点图片绑定；已绑定按 X 解绑 |
| Q / E（选中图片） | 旋转 ∓5°（Shift = ∓90°） |
| 滚轮 / Shift+滚轮 / Alt+滚轮 | 图片整体缩放 / 横向 / 纵向 |
| Ctrl+滚轮 / 右键拖动 | 画布缩放（0.4×~5×）/ 平移 |

## 五、工程文件 vs 导出格式

两套格式**不要混用**：

- **工程文件**（保存/打开）：编辑器内部格式，保留图标绑定元数据与画布坐标——工作存档，续作专用
- **导出 JSON**：`psapi.items/1` 内容包规范（[03 章](../03-items/02-items.md)解析器），给游戏加载用

改设计永远改工程文件再重新导出；直接改导出 JSON 的改动会在下次导出时被覆盖。

## 六、已知事项

1. **文件名冲突**：导出文件名取 id 冒号后的名部分——同工程里 `packA:gun` 与 `packB:gun` 撞名，导出时警告（后者覆盖前者）。跨包复用物品名时留意。
2. **重复 id 警告**：同工程内重复 id 在导出时警告。
3. 机器/配方/品质不在本工具范围：物品 JSON 导出后手补 `machine`/`qualities` 字段并配套目录文件（工作流：编辑器做物品与图标 → 手写数据面 JSON → `.pss` 写行为逻辑）。
