# 05 · 09 ui：界面函数

> `ui` 命名空间操控 PSUI 面板：开关、动态改文本/进度、读控件值、构建期动态填充、
> 机器绑定面板。**面板本身**（`.psui` 文件格式、元素类型、布局）是下一章
> [06 PSUI 教程](../06-psui/README.md) 的主题——本篇是函数手册，默认你已有面板可用。

## id 与元素引用规则

- **面板 id**：`"包id:面板名"`；脚本内引用**本包**面板可省略前缀（自动补）。
  引用他包面板写全名（对方没做隔离限制的话可以开别人的面板）。
- **元素 id**：`"[包:]元素id"`——同样缺省补本包。窗口 = 该包**当前面板**
  （最近打开的那张；没有打开的面板时报 `包 'xxx' 没有打开的面板 (先 ui.open)`）。
- `on_build` 构建期内解析**构建中的面板**，不受"须先打开"限制。

## 面板开关

| 函数 | 签名 | 返回 |
|---|---|---|
| 打开 | `ui.open(panel_id)` | `bool`（已打开则仅置顶，也返回 `true`） |
| 关闭 | `ui.close([panel_id])` | `bool`（未打开 = `false`） |
| 开着吗 | `ui.is_open([panel_id])` | `bool` |
| 重建 | `ui.rebuild([panel_id])` | `bool`（未打开 = `false`） |

`panel_id` 省略时作用于**本包最近打开的面板**（下文所有可选 id 同此约定）。
`open` 需对局内（CustomUIManager）；未知面板 id 报错并在消息里列出全部已注册面板名。
`rebuild` = 记忆窗口位置 → 关闭 → 按 `.psui` + `on_build` 重新构建——动态面板
"刷新数据"的标准做法（直接改文本嫌不够时用它）。

```pss
on shop_opened():
    if not ui.is_open("dashboard"):
        ui.open("dashboard")

on shop_closed():
    ui.close("dashboard")     # 打烊收面板
```

## 动态修改（面板打开后随时可调）

| 函数 | 签名 | 作用对象 |
|---|---|---|
| 改文本 | `ui.set_text(elem_id, text)` | label / button |
| 改进度 | `ui.set_progress(elem_id, value[, label])` | progress（`value` 0..1；`label` 可选刻度文本） |
| 通用写 | `ui.set_value(elem_id, v)` | 见下表别名行为 |
| 通用读 | `ui.get_value(elem_id)` | 见下表 |
| 首选尺寸 | `ui.set_pref_size(elem_id, w, h)` | 任意元素（`-1` = 该轴不指定） |

`set_value / get_value` 按元素类型分派：

| 元素类型 | set_value 接受 | get_value 返回 |
|---|---|---|
| progress | 数字 0..1 | `float` 0..1 |
| toggle | 任意值（真值判定） | `bool` |
| slider | 数字 | `float` |
| input | 任意值（格式化成串） | `string` |
| dropdown | 整数序号 | `int` |
| label / button | 任意值（等同 set_text） | `string`（文本） |

脚本回写**不会触发**该元素的 `on_change`（防自激循环）；玩家操作才会。

```pss
# 开店时刷新仪表盘
on shop_opened():
    var s = shop.status()
    ui.set_text("dash_title", "第 {time.rel_day()} 天 · 距交租 {s['day_until_rent']} 天")
    ui.set_progress("dash_queue", s["queue"] / 10.0, "队列 {s['queue']}")
```

## 图元槽位（slot / grid_slot 面板）

| 函数 | 签名 | 返回 |
|---|---|---|
| 槽内首件 | `ui.get_slot_item(elem_id)` | 物品句柄 \| `null`（空槽） |
| 槽内全部 | `ui.get_slot_items(elem_id)` | `[物品句柄]`（空槽 = 空表） |

slot 单物品槽用 `get_slot_item`；grid_slot 多物品格必须用 `get_slot_items`。
面板里没有该槽位时报错并列出已有槽位名。物品句柄见 [10 句柄](10-handles.md)。

## 动态构建（仅 on_build 构建期）

面板声明 `on_build` 后，每次构建（open/rebuild）会执行构建脚本，用 `build_*`
系列在静态树里**追加**内容（列表行、循环生成的按钮组……）。
**这些函数只能在 on_build 块里调用**，别处调用报
`ui.build_* 仅可在面板的 on_build 构建期调用(动态内容变化请 ui.rebuild 重建)`：

| 函数 | 签名 | 说明 |
|---|---|---|
| 进容器 | `ui.build_begin(container_id)` | 推进静态树里**带 id 的容器**（row/column/grid/scroll 写了 id 才能定位），后续 build_* 落入其中 |
| 开横排 | `ui.build_row([spacing = 4])` | 新建横向容器 |
| 开纵列 | `ui.build_column([spacing = 4])` | 新建纵向容器 |
| 开滚动 | `ui.build_scroll(height)` | 新建滚动区（内容超高滚动） |
| 闭合 | `ui.build_end()` | 配对最近的 begin/row/column/scroll |
| 加标签 | `ui.build_label(text[, {id, tooltip}])` → 元素id | |
| 加按钮 | `ui.build_button(text, fn名[, {id, arg, tooltip}])` → 元素id | 点击调本包全局函数 |

`build_begin` 与 `build_row/column/scroll` 都必须用 `build_end` 闭合（嵌套同理）。
省略 `id` 时自动生成（`__dyn1`、`__dyn2`……）。

**按钮回调约定**：`fn名` 是**本包**顶层函数名（字符串）。函数带 1 个参数收
`{elem = 元素id, arg = 你传的 arg}`；0 参则空调用。`arg` 常用来区分循环生成的
一排按钮：

```pss
# .psui 面板声明 on_build 后, 构建脚本里(example_hello 演示同款思路):
ui.build_begin("item_list")               # 静态树里带 id 的容器
var r = items.browse(8, "", 0, 14)
for e in r["items"]:
    ui.build_button("{e['name']} ¥{e['value']}", "on_pick_item", {arg = e["id"]})
ui.build_end()

func on_pick_item(info):
    log.info("选中了 {info['arg']}")
```

## 机器绑定面板（v1.4.0）

`machines/*.json` 声明 `ui = "psui"` 的机器会绑定一张面板（打开机器即开面板，
见 [03 · 数据面 JSON](../03-items/README.md)）。这组函数的首参 `machine` 是
**机器物品句柄**——来自机器面板回调参数或 `ui.machine_find_uid(uid)`：

| 函数 | 签名 | 一句话 |
|---|---|---|
| 找机器 | `ui.machine_find_uid(uid)` | 按存档稳定 uid 找 psui 机器 → 物品句柄 \| `null` |
| 开着吗 | `ui.machine_is_open(machine)` | 该机器的面板是否打开 |
| 改文本 | `ui.machine_set_text(machine, elem_id, text)` | 面板内改文本 |
| 槽内首件 | `ui.machine_slot_item(machine, slot_id)` | → 物品句柄 \| `null` |
| 槽内全部 | `ui.machine_slot_items(machine, slot_id)` | → `[物品句柄]` |
| 白名单 | `ui.machine_set_whitelist(machine, slot_id, [ids])` | **覆盖式**重设槽位排他白名单 |
| 槽内生成 | `ui.machine_spawn(machine, slot_id, item_id[, count = 1])` | 造新物品直接进槽（输出槽预览用）→ 句柄 \| `null` |
| 双锁 | `ui.machine_lock(machine, slot_id, locked)` | 插入锁 + 取出锁（锁定后玩家放不进也取不出） |
| 清槽 | `ui.machine_clear(machine, slot_id)` | 槽内物品**全部销毁**（清预览） |

设计意图：机器面板的输入/输出槽是**真库存槽**——玩家把材料放进槽、脚本用
`machine_slot_item(s)` 读材料、用 `machine_spawn` 放产出预览、`machine_lock`
锁住防误取、`machine_clear` 清掉预览。配合数据面配方系统实现自定义加工台。
深入玩法见 [07 进阶](../07-advanced/README.md)。
